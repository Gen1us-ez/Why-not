# 🍩 GLAZE CRAFT — Artisan Donut Studio Website

A modern, interactive, and responsive test website showcasing handcrafted brioche donuts.

---

## 🚀 Quick Start / How to Open

No Node, Python, or build step required! You can open it directly in any browser:

### Option 1: Double-Click
Simply navigate to this folder and double-click:
```
index.html
```

### Option 2: PowerShell Shortcut
Run this command from PowerShell:
```powershell
Start-Process .\index.html
```

## ✨ Key Features & Interactive Capabilities

1. **🔥 Live "Hot Light" & Countdown Banner**:
   - Visual indicator showing when fresh batches come out of the oven.
   - Real-time countdown timer to the next warm batch drop.

2. **🍩 Interactive Hero Showcase**:
   - Animated SVG donut with real-time glaze swatches.
   - Click color swatches to instantly transform the donut's glaze and drizzle.

3. **🎨 The Custom Donut Lab (Build-Your-Own)**:
   - Choose your dough base (Brioche, Red Velvet, Churro Spiced, Black Sesame).
   - Pick hand-dipped glazes (Wild Strawberry, Belgian Ganache, Uji Matcha, Salted Caramel, Ube).
   - Select toppings (Rainbow Jimmies, Roasted Nuts, Cocoa Nibs, Candied Bacon, 24K Gold, Coconut Snow).
   - Customize drizzle lines with live SVG rendering and add your custom creation directly to your box!

4. **📦 Interactive 6-Pack Box Builder**:
   - Visual pastry box with 6 slots.
   - Slots dynamically fill up as you add donuts with miniature visual previews.
   - Automatic **10% bundle discount** activated when 6 slots are filled.
   - 1-click **"Crowd Pleaser" 6-Pack** bundle shortcut.

5. **🔮 "Find Your Soul Donut" Matchmaker Quiz**:
   - 3 interactive craving questions (Vibe, Sweetness, Texture).
   - Computes your match and generates a custom recommendation card with direct 1-click add to box.

6. **🛒 Slide-Over Cart Drawer & Checkout**:
   - Toggle between **Hot Delivery (35m)** and **Store Pickup (10m)**.
   - Live pricing calculation (Subtotal, 10% Box Discount, Delivery, Tax, Total).
   - Promo code support: Try codes `SWEET10` or `FIRSTBITE` for $3.50 off.
   - Checkout simulation with celebratory confetti burst and order confirmation receipt (`GC-XXXXXX`).

7. **🔍 Quick View Modal**:
   - Nutritional facts (calories, sweetness rating, crunch index).
   - Allergen badges (Gluten, Dairy, Eggs, Nuts, etc.) and culinary tasting notes.

8. **🚚 Real-time Delivery Radius Checker**:
   - Test your 5-digit ZIP code (e.g. `90210`, `10001`) to verify local hot delivery coverage.

9. **🔊 Synthesized Web Audio Sound Effects**:
   - Gentle, harmonic sound effects for donut selections, toppings crunch, and confetti chimes generated entirely via the Web Audio API (zero external audio file dependencies!).
   - Sound toggle button in the navbar to mute/unmute anytime.

10. **✨ Sprinkle Click Burst**:
    - Interactive cursor sprinkle particle explosions on clicks throughout the page.
